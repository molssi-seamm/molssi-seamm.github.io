****************************
Installing SEAMM using Conda
****************************

SEAMM is no longer installed into a conda environment. It is now installed with the
SEAMM Manager, which uses ``uv`` and needs conda only for the external codes such as
MOPAC and LAMMPS. See :ref:`seamm-manager-installation`, and
:ref:`migrating-from-seamm-installer` if you have an existing conda-based installation.
